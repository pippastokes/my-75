# My 75

A personal, installable 75-day consistency tracker designed for iPhone and hosted free with GitHub Pages.

## Core habits
- 30 minutes phone-free before bed
- 2 litres of water
- Make my bed
- Skincare
- 30 minutes prep for tomorrow

## Extra Wins
- Movement
- Nourishing meal
- Outside time
- Reading
- 7+ hours sleep
- Up before 7am

## Built-in rules
- 75 consecutive calendar days
- 5 Flex Days; they count within the 75 but are excluded from consistency scoring
- Flex Days must be planned in advance
- Today can be edited until submitted
- Submitted days are permanently locked
- A forgotten past day can be backfilled once, then locks immediately
- No future-day logging
- Test Mode is included before starting the real challenge
- Data is stored locally in the browser/device
- Backup export/import is included

## Put it online for free with GitHub Pages
1. Create a free GitHub account if you do not already have one.
2. Create a new **public** repository called `my-75`.
3. Upload every file and folder from this project, keeping the `icons` folder intact.
4. Open the repository, then go to **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose the `main` branch and `/ (root)` folder, then Save.
7. GitHub will show the published site URL once Pages is enabled.

## Add it to your iPhone Home Screen
1. Open the published GitHub Pages URL in Safari.
2. Tap the Share button.
3. Tap **Add to Home Screen**.
4. Keep the name as **My 75**, then tap Add.
5. Open it from the new Home Screen icon.

## Important data note
The app stores challenge data locally on that device/browser. Use **Me → Export Backup** regularly. Clearing Safari website data or removing stored website data can erase local progress.
